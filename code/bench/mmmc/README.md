# MMMC TeachQuiz questions

`questions.json` is `json_files/questions_by_topic_10.json` from Code2Video
(https://github.com/showlab/Code2Video, MIT licence, `LICENSE-Code2Video`). It holds 117 topics with 5 multiple-choice
questions each, despite the file's name. These are the official TeachQuiz questions of the MMMC benchmark
(https://huggingface.co/datasets/YanzheChen/MMMC). In c2v-lab they are the TEST quiz: no repair step ever sees them.
